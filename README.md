Gerenciador Inteligente de Tarefas

Projeto desenvolvido para a disciplina de Programação Orientada a Objetos.

Objetivo

Desenvolver um sistema de gerenciamento de tarefas utilizando os conceitos de Programação Orientada a Objetos.

Funcionalidades

Cadastro de usuários
Cadastro de projetos
Criação de tarefas
Definição de prioridade
Alteração de status das tarefas
Acompanhamento do progresso do projeto

Python

Visual Studio Code
